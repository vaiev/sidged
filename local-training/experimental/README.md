# Experimental trainers (archived)

- `train_edge_llm.py` (Model 0, A2UI composer) and `train_planner_think.py` (Model 1 planner experiment) are
  demo trainers: they learn a few fixed templates, are not on the runtime path and have no release gate. Kept for
  reference; the companion linguist (Model -1) in the parent directory is the trained model that ships.
